# Правила пользователя

- Коммитить завершённые изменения локально. Не упоминать AI-соавторство в сообщениях, теле и трейлерах коммитов; не добавлять Co-Authored-By от ассистента. Использовать настроенного автора Git.
- Никогда не выполнять push, включая косвенный push через другие инструменты.
- Адаптацию CV для Internet Revolution сначала показывать пользователю. Публикация — только после его одобрения.
